# La😂Print Web

Drift-backed frontend for the La😂Print automated trading terminal.

## Routes
- / — landing
- /connect/fund — wallet/funding entry
- /tier — leverage vs spot
- /autopilot/setup?tier=leverage|spot — strategy configuration
- /dashboard — terminal dashboard
- /positions — positions
- /fees — fee breakdown

## Status
UI foundation only. Wallet signing, Drift account reads, live engine state, and transaction submission must be connected to the production engine before live actions are enabled.
